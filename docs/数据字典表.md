## 1. 文档说明

### 1.1 目的
- 统一全系统字段、枚举、主数据的定义与取值标准，作为数据治理、清洗、打标和系统改造的依据。
- 消除当前数据中“同义不同写、全角半角混用、枚举自由填写、双存储漂移”等问题。

### 1.2 数据源现状（治理后）
| 项 | 现状 | 建议 |
|---|---|---|
| 运行存储 | SQLite（`data/合同台账.db`）为系统实际读写库，A-05 重建后 schema 版本 v3 | 确定为唯一权威数据源 |
| 交付存储 | Excel（`data/合同台账.xlsx`）用于导入/导出、人工查阅（模板/导入为 29 列） | 仅作导出交付物，禁止直接修改后回灌 |
| 备份 | `backups/` 自动备份，保留 30 天 | A-01~A-08 治理已完成，后续再治理前追加快照备份 |
| 双库一致性 | 历史上 Excel 与 SQLite 多次不一致（如部门字段） | A-03 已修复 71 条缺科室后缀部门数据，每次治理后校验两库差异并出具报告 |
| 治理状态 | 枚举已标准化（A-08）、部门已修复（A-03）、日期已规范化（A-05/A-06） | 金额文本 245 条仍待业务确认（见 A-05/A-06 清单） |

### 1.3 角色与权限（引用）
| 角色 | 权限 |
|---|---|
| 管理员 | 维护用户/部门/系统配置；操作全部合同；打标治理 |

| 业务属性 | 重点合同 | 是/否 | 金额大、影响面广，需重点跟踪 | 人工 |

| 生命周期 | 进行中 | 是/否 | 未完工未结算 | 自动 |
| 生命周期 | 已完工 | 是/否 | 完工时间非空 | 自动 |
| 生命周期 | 已结算 | 是/否 | 是否结算=是 | 自动 |
| 生命周期 | 已验收 | 是/否 | 竣工验收时间非空 | 自动 |
| 生命周期 | 超期未验收 | 是/否 | 完工超期仍无验收时间 | 自动 |

| 数据质量 | 人名不一致 | 是/否 | 与用户主数据不符 | 自动 |
| 数据质量 | 待人工复核 | 是/否 | 自动规则无法判定 | 自动 |

### 6.3 打标顺序
1. 自动质量标签（数据清洗完成后重跑）；
2. 自动业务/风险标签；
3. 人工业务标签（延续性项目、重点合同）——建议先标注“延续性项目”，直接服务重新采购提醒。
