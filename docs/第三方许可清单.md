## 三、许可义务与合规说明

- **MIT**：需在副本中保留版权与许可声明。本项目各本地化文件头已保留原版权声明，满足义务。
- **Apache-2.0**：需随分发保留许可证副本（本清单已归档至 `docs/licenses/Apache-2.0.txt`）；对源文件进行修改时应在修改文件处标注变更。
- **BSD-3-Clause**：需保留版权声明，且不得使用版权所有者名称对衍生品作背书。
- **Unlicense**：公有领域贡献，无保留义务。

## 四、维护建议

1. 升级任一前端组件或 Python 依赖时，同步更新本清单中的版本号，并替换 `docs/licenses/` 中对应的许可证全文。
2. 部署服务器上执行 `pip freeze` 后，可将实际安装版本回填至第二节表格，保持与运行环境一致。
3. 如需对外分发或接受上级审查，建议将本清单与 `docs/licenses/` 目录随系统一同归档。
