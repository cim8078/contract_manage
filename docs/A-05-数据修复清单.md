第一节：自动回填 697 条（迁移时已实际写入数据库）
依据是 A-05 任务要求——9 个必填列加 NOT NULL、5 个日期列加 YYYY-MM-DD CHECK，存量数据必须先满足新约束才能重建表。逐类规则：
- 资金来源为空 → 回填"其他"（635 条）：必填字段兜底枚举，不编造具体来源。

第二节：金额列非数字文本 245 条（仅列出建议，本次未自动修改）
- 判定规则：金额列（合同金额/结算金额/已支付/未支付/决策的招标控制价）存在非数字文本，如"按实结算"、"54（3年）"、"0.518元/KWH"、"/"、"是/否"、长说明。分布：决策的招标控制价 63、已支付 58、未支付 45、合同金额 43、结算金额 36。
- 不自动改写的原因：金额 CHECK 是 CAST(字段 AS REAL) >= 0，文本 CAST 后为 0、满足约束，迁移不阻塞；若按"提取首个数字"处理会误判——"潭财办发[2014]15号"→2014、"代为支付2025年…"→2025、"不足2000元按2000元包干"→2000 都不是合同金额；且"万元/年"等口径不做换算，避免静默篡改业务数据。
- 表中"建议值"列 = 正则提取的首个数字，仅作人工参考；"无法解析" = 纯文本无数字。请业务核对后通过"修改合同"表单或 SQL 手动修正。
共性原则
- 只做可明确判定、可逆的修复；凡涉及金额口径/业务含义的一律不猜、不改，全部逐条列"原值→新值→依据"供复核；
