# 新增「资产合同」菜单与「资产合同台账」操作页面

> 目标：参照「项目合同」菜单与「项目合同台账」操作页面，在系统中新增「资产合同」菜单及对应的「资产合同台账」操作页面，数据落在已建好的 `asset_contracts` 表。
> 变更日期：2026-09-20　|　范围：1 个菜单项 + 1 个操作页面（含新增/编辑/删除/导出/模板/导入）+ 对应后端接口；原有菜单、页面与接口均未改动。
> **更新（V1.1，2026-09-23）**：页面在首版基础上陆续补齐**管理部门/责任人字段**、**归档**、**附件（决策依据附件/合同附件）**、**提醒提前天数**、**序号按 id 降序**、**部门范围过滤**，并新增「资产合同查询统计」选项卡页面；本文档第 1~4 节按该版本实现同步更新（**其中列数、区块划分、附件类型等已由下方 V1.2 更新覆盖，请以 V1.2 说明与《数据字典表》V1.4 为准**）。
> **更新（V1.2，2026-09-29）**：
> ① 列表**取消“缴款方式”列**（列宽重排为 11 列合计 100%，操作列 13%），搜索筛选同步取消该项；表头“年租(元)”改称“**年租金(元)**”；“已缴租金合计(元)”改为按租金收取明细实缴金额自动汇总。
> ② 编辑弹窗改版：“资产与承租人信息”区第二行为 面积/租期开始日/租期结束日/租期，第三行为 **年租金（元）/总合同额/押金（元）/下次出租时间**；**取消原“租金信息”区**；**“责任人”“提醒提前天数”移至“管理部门”行**（管理部门/责任人/提醒提前天数/备注 四列对齐）；原“已缴租金明细”区重构为 **“租金收取明细”动态表格**（收款期次/所属租期开始日/所属租期结束日/应缴金额/实缴金额/缴款日期/缴款方式/收款人/操作 + 底部应缴·实缴·差额汇总；缴款方式为枚举下拉且默认“直缴非税”；归档或查询用户时整表只读）；附件区新增 **“资产现状图片”**（共三类）。
> ③ 删除合同时若存在租金收取记录，确认框与接口都会提示“将一并删除 N 条记录”，未确认由数据库 RESTRICT 兜底拒绝。
> ④ 视觉：弹窗极简风（浅灰表头 `#fafafa` + `1px #ebeef5` 下边框、数据居中、无横向滚动）；两个合同编辑弹窗位置与宽度统一（顶距 5vh、`max-width:1000px`）。

## 2. 后端接口（app.py）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/asset_contracts` | 列表：筛选 + 分页，返回 `items/places` |
| POST | `/api/asset_contracts` | 新增（必填：位置、资产名称、承租人；金额非负；日期 yyyy-mm-dd） |
| GET | `/api/asset_contracts/<arow_id>` | 单条详情 |
| PUT | `/api/asset_contracts/<arow_id>` | 修改（支持部分字段） |
| DELETE | `/api/asset_contracts/<arow_id>` | 删除（需填写删除原因） |
| GET | `/api/asset_contracts/export` | 导出 Excel（按当前筛选条件） |
| GET | `/api/asset_contracts/template` | 下载导入模板（管理员） |
| POST | `/api/asset_contracts/import/preview` | 导入预览与逐条校验（管理员） |
| POST | `/api/asset_contracts/import` | 导入（管理员，错误行跳过并回显原因） |
| PUT | `/api/asset_contracts/<arow_id>/archive` | 归档（管理员或该合同责任人；归档后只读） |
| PUT | `/api/asset_contracts/<arow_id>/clear_remind` | 清空“下次出租时间”（首页提醒“永久关闭”） |
| POST | `/api/asset_contracts/<arow_id>/attachments` | 上传附件（决策依据/合同；格式白名单 + 大小限制） |
| GET | `/api/asset_attachments/<att_id>/download` | 附件下载（按“管理部门”数据权限校验） |
| DELETE | `/api/asset_attachments/<att_id>` | 删除附件 |
| GET | `/api/asset_statistics?type=...` | 资产合同统计（by_dept / by_person / by_time，支持 unit/dept/person/start_date/end_date） |

字段映射见 `ASSET_FIELDS`（接口字段名 ↔ 数据库列名），与导出/模板/导入共用，保证三者列一致。

## 3. 权限与其他说明

- 角色沿用系统既有规则：管理员与普通用户可新增/修改/删除；**查询用户只读**（接口返回 403，页面隐藏编辑/删除按钮）；模板与导入仅管理员可用；**归档**仅管理员或该资产合同“责任人”可执行。
- **部门范围过滤（v6 起）**：资产合同按「管理部门」列过滤——管理员可见全部；普通用户与查询用户的可见范围＝本部门 + 分管部门（`_scope_assets()`）。该口径统一应用于列表、详情、统计、导出、附件下载，以及首页「总合同数 / 总合同额 / 已-将到期合同数」卡片与到期提醒中的资产部分。
- 所有写操作（新增/修改/删除/归档/导出/下载模板/导入/附件上传与删除/清空提醒）均写入 `operation_logs`，模块名为「资产合同台账」；字段级修改同时写入 `field_change_logs`（模块名同为「资产合同台账」）。
- 资产合同已具备归档与附件能力：归档后记录只读（不可编辑/删除/上传删除附件、不可“永久关闭”提醒，仅可“忽略”）；附件为“决策依据附件 + 合同附件”两类，选填。

## 4. 验收结果（已实测）

**接口层（基于数据库副本，全部通过）**
列表/位置下拉、按位置/资产名称/承租人/管理部门/责任人/序号/缴款方式/租期结束日区间/归档状态筛选、分页（id 降序）；新增（必填校验、负金额、非法日期均被拒绝）、单条查询、修改、删除（未填原因被拒绝）；归档（归档后修改/删除返回 403）；附件上传（格式/大小校验）、下载、删除；导出 xlsx（表头/行数正确）、下载模板、导入预览（1 可导入 + 1 校验失败）、导入（新增 1 跳过 1，数值正确入库）；清空提醒（`clear_remind`）；`/api/asset_statistics` 三种维度；查询用户对新增/修改/删除/归档/附件上传均返回 403；**部门范围过滤**：国资组用户列表 5 条、他部门用户 0 条且详情/附件下载 404；项目合同 639 条、仪表盘、统计、导出、用户/部门/日志接口均正常。

**界面层（真实浏览器 Edge + 正式库副本）**
